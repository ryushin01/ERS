# ERS Storybook

**ERS**(전자등기 관리 시스템)의 컴포넌트 문서입니다. 모든 컴포넌트를 앱과 같은 환경에서 바로 확인할 수 있습니다.

화면의 데이터는 모두 데모 목업 API가 만든 가상 데이터입니다. 백엔드 없이 앱과 같은 데이터 흐름으로 동작합니다.

## 구성

| 분류                                                | 내용                                       |
| --------------------------------------------------- | ------------------------------------------ |
| Foundations                                         | 타이포그래피 단계                          |
| Common · Button · Form · Modal · Drawer · Accordion | 공통 UI 컴포넌트                           |
| Layout · Error · Login                              | 헤더·메뉴·레이아웃, 오류 화면, 로그인 화면 |
| Financial · Admin · Registration                    | 금융기관·관리자 업무 화면과 하위 표·팝업   |

## 둘러보는 방법

- **Docs**: 컴포넌트 설명과 속성 표, 전체 스토리를 한 페이지에서 봅니다.
- **Controls**: 크기·색상·상태 같은 속성을 바꿔 봅니다.
- **Viewport**: 툴바에서 Mobile·Tablet·Desktop을 골라 화면 크기별 레이아웃을 확인합니다.
- **Accessibility**: 스토리의 접근성 검사(axe) 결과를 확인합니다.

## 테스트

모든 스토리는 `pnpm run test:storybook`으로 실제 브라우저에서 렌더링되고, 접근성 위반이 있으면 실패합니다. CI에서도 실행합니다.
